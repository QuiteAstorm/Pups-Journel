# 🐶 Pup's Journal

A colorful, phone-friendly programming journal with expandable sections, branch diagrams, and short educational code examples.

After GitHub Pages is enabled, the journal will be available at:

**https://quiteastorm.github.io/Pups-Journel/**

The website is in [index.html](./index.html).

## Publish

1. Merge the pull request into main.
2. Open repository **Settings → Pages** and select **GitHub Actions** under Build and deployment.
3. Open **Actions → Publish Pup's Journal** and check for a successful deployment. Use **Run workflow** if needed.

This is a public learning journal, separate from the private application repository. Do not put private information, secrets, or proprietary source files here.
