# Behind the Puppy Paws — Coding Workshop

> **Status:** Planning scaffold only. No private workshop access or authentication is implemented.

This is the public-safe outline for a future coding workshop associated with Pup's Journal. The existing build diary remains separate.

## Learning path

1. **HTML fundamentals:** semantic page structure, forms, accessibility.
2. **CSS fundamentals:** selectors, box model, responsive layouts, flexbox and grid.
3. **Bootstrap:** components, grid, customization, and mobile layouts.
4. **JavaScript:** variables, functions, objects, events, DOM, promises and asynchronous code.
5. **TypeScript:** types, interfaces, modules, and type-safe application design.
6. **Angular:** components, templates, signals, services, routing, forms and testing.
7. **Databases and MongoDB:** documents, collections, queries, and database interfaces.
8. **Putting it together:** a separate practice application, deployment and troubleshooting.

## Lesson template

Each lesson should include:

- **Goal:** what the learner will build and why.
- **Concepts:** technical explanations with diagrams where useful.
- **Code walkthrough:** real, runnable *practice* examples.
- **Decisions:** tradeoffs and alternatives.
- **Verification:** how to test the result.
- **Quick reference:** commands, patterns and definitions.
- **Practice:** optional, repeatable exercises.
- **Resume point:** what was finished and what comes next.

## Public versus private

**Public workshop:** use fictional practice apps, generic components, and sanitized examples. Do not copy proprietary application code, credentials, user records, internal configuration or private notes.

**Private workshop (future):** may reference actual Happy Furrbabbies architecture and development history, but only after real authentication and authorization have been designed and verified. A hidden menu link is not access control. Until then, keep private material outside this public repository and deployed pages.

## Visual reference topics

- Mobile menu design progression: from decorative bone buttons to compact, legible controls.
- Dropdown interaction and state management.
- Responsive layouts and overflow behavior on narrow screens.
- Horizontal carousel navigation and accessible controls.
- Contrast, readable text and screen-reader support.
