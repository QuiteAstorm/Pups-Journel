How we handled a merge conflict

How we handled a merge conflict

Two feature branches changed overlapping parts of a website. GitHub could not safely combine them on its own.

Instead of struggling with the older branch, we started a new branch from the updated main branch and carefully reapplied the intended feature. A fresh branch doesn't automatically solve conflicts: the changes still need to be combined thoughtfully.

Lesson: A green build check and a conflict-free merge are different things. Both matter.

What is a pull request?

What is a pull request?

A pull request proposes bringing changes from one branch into another. Review the changed files, automated checks and merge status before merging.

🗺️ Site map: public visitors, parents, dogs, and helpers

Different spaces, one dog-loving community

The public welcome page introduces Happy Furrbabbies. After joining or exploring, the community has different spaces for Pet Parents, Furrbabies, and Dog Lovers Without Paws. The public menu and inside menus must be developed independently.

Navigation decisions: Home returns to the Pet Parent area after member entry; the public menu title returns to the outside homepage. The dog-owner menus should be compact and not obscure content while scrolling.

🦴 Posts, feeds, treats, and puppy dances

Making every puppy feel celebrated

Design decisions: Community posts can be directed to My Dog Feed, Community, or both. Comments should collapse, replies should be possible, and owners should not award treats to their own posts. The feed should not jump to the top after posting.

Treat rules: A post may record at most five total treats in any combination. Further taps can still make the puppy dance without increasing the recorded count. No dislikes. Five gentle animation ideas were approved: wiggle, bounce, head tilt, silly spin, and a combined happy dance.

Still being verified: Shared treats between the two invited testers' phones, notifications, and abuse protection. Saved Memories is intended for a person's own posts, not unrestricted copying of community content.

🔐 Cloudflare, accounts, and our two invited testers

The plumbing behind the puppy paws

Think of the website as a house: Angular is what visitors see, Cloudflare Workers handle requests, and D1 is the database behind the walls. A Cloudflare Access gate is intended to guard the private testing endpoints.

Recovered implementation: Prototype protected endpoints, D1 binding and database preparation/inspection workflows were developed in PRs #193–#197. A separate Tester Tools page was added in #232.

Not yet proven: That the allowlist is limited to precisely two accounts, that the full account system is production-ready, or that treats sync successfully between devices. Never publish personal tester emails, secrets, or private health records in this public journal.

🏡 Helping Paws, Furrever Sanctuaries, and rescue

The mission beyond the website

Agreed program names: Furrever Dog Sanctuaries provides lifelong loving sanctuary care; Furrever Dog Rescue & Adoption helps rescue dogs and find loving families. Both belong under Happy Furrbabbies, with dogs as the primary focus.

Helping Paws: Volunteer help is the starting point; paid providers should be clearly distinguished. Community members should control whether providers may contact them. Rescue ideas include nearby shelters, a Need Help route, and thoughtful rehoming arrangements.

Sanctuary planning studio: A free library of sanctuary ideas, sketches, layouts, and 3D concepts, searchable by capacity and customizable by others. The land-needs calculator is a planning concept; plans do not have to be construction-ready. Optional creator credit and attribution for adaptations were discussed.

Founder principle: “Happy Furrbabbies does not belong to them, it belongs to the dogs.” This expresses the mission: future leaders are stewards, while legal nonprofit ownership and governance must follow applicable law.

Governance is still planning, not an operating nonprofit: Virginia incorporation, board succession, director appointments, strategic approval versus daily sanctuary management, donation tracking, and emergency contingencies require legal and benefits review. Sanctuary Managers would handle daily care and urgent animal needs. Do not treat proposed policies as legally adopted.

🎨 Accessibility, decoration, and things still on the list

Little details that matter

Design preferences: Bold dark readable text, cheerful dog-first colors, phone-friendly menus, playful cursive headings where legible, and no unwanted purple takeover. Owner and dog profiles may be decorated, but site-wide chrome should stay consistent.

Accessibility: A central settings area should coordinate options across pages while individual controls remain available. Read-aloud support, screen-reader labels, color-blind-friendly palettes, and reduced-motion behavior are important. Automatic carousel scrolling was requested ON by default, with pause and user controls; reduced-motion preferences should take priority.

Feed and carousel goals: Smooth horizontal swiping without jumps, pause on touch, small discreet controls, and a friendly “You've reached the end of the puppy parade” message.

Account and safety goals: Real email/PIN or password login, secure private messages, moderation/blocking, and private veterinary/care records still require careful implementation and testing. Do not assume preview screens are secure accounts.

Behind the Puppy Paws: Our journal can keep short, anonymous lessons about bugs, GitHub merges, and the fun of learning how the site fits together—without sharing private information.

Angular code snippets

decoratingDogSlide = signal(0);
moveDecoratingDogSlide(delta: number) {
  const count = this.dogs().length;
  if (count) this.decoratingDogSlide.update(
    index => (index + delta + count) % count
  );
}

The signal stores which card is selected. The modulo operator wraps around: moving next from the final card returns to the first. We check the count first to avoid dividing by zero.

This second snippet is a simplified teaching illustration. The live Angular template calculates the counter from decoratingDogSlide() and dogs().length.
