How we handled a merge conflict

How we handled a merge conflict

Two feature branches changed overlapping parts of a website. GitHub could not safely combine them on its own.

Instead of struggling with the older branch, we started a new branch from the updated main branch and carefully reapplied the intended feature. A fresh branch doesn't automatically solve conflicts: the changes still need to be combined thoughtfully.

Lesson: A green build check and a conflict-free merge are different things. Both matter.

What is a pull request?

What is a pull request?

A pull request proposes bringing changes from one branch into another. Review the changed files, automated checks and merge status before merging.

Angular code snippets

decoratingDogSlide = signal(0);
moveDecoratingDogSlide(delta: number) {
  const count = this.dogs().length;
  if (count) this.decoratingDogSlide.update(
    index => (index + delta + count) % count
  );
}

The signal stores which card is selected. The modulo operator wraps around: moving next from the final card returns to the first. We check the count first to avoid dividing by zero.

October 27, 2026 — Accessibility: one main panel, individual switches ⚙️🐾

One main panel, individual switches

Think of it like the electrical system in a house. You have one main panel, but every room still has its own switches!

Our plan: one easy-to-find accessibility menu on every Happy Furrbabbies page. It shares settings with the Community Feed, carousels, videos and dog Playgrounds, while each feature keeps its own necessary controls.

What visitors will be able to do

  • Use a central menu to adjust text size, contrast, motion, carousel speed and video preferences.
  • Use direct play/pause, volume and caption controls on videos; pause and navigation controls on carousels.
  • Enjoy carousel auto-scroll normally on at five seconds, with choices of 3, 5, 8 or 12 seconds. Respect reduced-motion preferences and pause on interaction.
  • Reach the end of the Community Feed and meet a waving puppy saying, “You've reached the end of the puppy parade!” with a Back to Top button.

Important: This is a design and learning diagram, not a claim that the shared accessibility system is already installed. Each feature still needs keyboard, screen-reader, focus and caption testing.
